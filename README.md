## Комментарии
продолжаем обсуждать библиотеку baseline-browser-mapping, тк уже второй человек мне написал, что это сторонняя библиотека.

Эта библиотека — инструмент настройки, который поставляется вместе с Vite. Она нужна исключительно для решения одной задачи: определения минимально необходимых версий браузеров, которые поддерживаются проектом.

Когда Vite собирает проект, он должен решить до какой версии JavaScript (ES5 или ES2015) нужно конвертировать код, чтобы он гарантированно работал у пользователей. Для этого Vite обращается к справочным данным, в том числе к этому пакету, чтобы узнать — например, поддерживает ли текущая версия Chrome нужные функции.


## Как начать

1. Установите зависимости:
```bash
npm ci
```
  
2. Запустите проект в dev режиме:
```bash
npm run dev
```

3. Сборка проекта в build версию:
```bash
npm run build
```
