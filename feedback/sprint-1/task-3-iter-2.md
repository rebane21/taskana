- **Проблема:** при фокусе появляются тени между обводкой и контентом — некорректно. Между обводкой и контентом должно быть белое пространство.
**Причина:** в текущей реализации **border-radius**, **outline** и **outline-offset** задаются только в **:focus-visible**
**Рекомендация:** базовые стили вынести в основной класс, а в **:focus-visible** менять только цвет **border** и **outline**.
Пример:
.class {
**border: 2px solid transparent;**
**outline: 2px solid transparent;**
}
.class**:focus-visible** {
**border-color: var(--base-black);**
**outline-color: var(--base-white);**
}
